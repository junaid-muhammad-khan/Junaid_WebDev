# Junaid_WebDev

Web development coursework — HTML/CSS labs and a full multi-page site assignment, built while learning front-end web fundamentals.

## Structure

```
assignments/
  assignment-3-fish-creek-animal-hospital/   A full multi-page site (Fish Creek Animal
                                              Hospital): home, about, services, shop,
                                              contact, a survey form, and an "Ask the
                                              Vet" page with embedded video, plus the
                                              write-ups for Assignments 2 & 3.

labs/
  lab2/            HTML fundamentals exercises.
  lab3-practice/   Inline, embedded, and external CSS practice (colors, formatting,
                   applying the same styles three different ways).
  lab4/            A small "DogLife" pet-adoption site with a sitemap, wireframe,
                   and page-selection flow.
  lab6/            A movie page, a music survey form, and a custom HTML form.
  lab7/            Multimedia lab: an image gallery, embedded audio/video across
                   formats (m4v/mov/webm/ogv), and an interactivity demo.

resources/
  web dev book.pdf   Course reference text.
```

## Viewing

Each lab/assignment is a static site — open its `index.html` (or the relevant page) directly in a browser, no build step required.

## Note

This is coursework kept as a personal record; duplicate copies of the Assignment 3 site and unused raw media dumps from the original Lab 7 folder were removed to keep the repository to what's actually used by the pages.
